# gender-pay-gap-analysis
Beginner SQL and data analysis project examining the US gender pay gap from 2018-2024 using data from the  Bureau  of Labor and Statistics, cleaned data in excel and sheets. Used BigQuery to simplify tasks and Looker Studio for charts. A personal project of mine, in celebration of Women's Month this March 2026, built to practice data analytics skills using real world data.

## Skills Practiced:
- Data Cleaning & Organizing
- SQL Querying using BigQuery
- Data Visualization using Looker Studio

## Data Source
U.S. Bureau of Labor Statistics, Current Population Survey (2018–2024)
(https://www.bls.gov/cps/tables.htm#otheryears)
